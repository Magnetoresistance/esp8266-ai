网页一键烧录Flash from the browser

在浏览器里完成烧录，不装任何工具。本页固件适配 1MB Flash 的 ESP-12S（DOUT 模式）。

1插上设备用 USB 数据线连接设备与电脑（很多线只能充电，烧不上请先换线）。
2连接并烧录点下方按钮，在弹窗里选中串口（Windows 通常是 CH340 开头的 COM 口）。
3等待完成烧录约 30~60 秒，设备自动重启开机，随后按屏幕提示配网。
当前浏览器不支持 Web Serial —— 请使用桌面版 Chrome 或 Edge 打开本页（手机与 360 / QQ 等浏览器不支持）。 浏览器未授予串口权限，请在弹窗中点击「允许」。

烧录常见问题Troubleshooting

按设备管理器 / 浏览器表现对号入座。

Windows设备管理器里看不到 CH340 串口
先换一根 USB 数据线（多数线只能充电），并换个 USB 口。若仍没有，安装 CH340 驱动（CH341SER.EXE）后重新插拔。
WindowsCH340 带黄色感叹号，提示「该设备无法启动 (代码 10)」
板载 CH340 是兼容芯片，被新版官方驱动拦截：卸载现有驱动，改装 CH341SER 3.5 旧版驱动；设备管理器里右键设备 → 更新驱动程序 → 浏览计算机 → 选择旧版本。
Windows串口一切正常，但浏览器弹窗里没有端口
用官方 Chrome 或 Edge 重新打开本页（360、QQ 等浏览器阉割了 Web Serial），并关闭 Arduino IDE、串口监视器、桥接程序等占用串口的软件后重试。
Windows串口芯片不是 CH340？
看一眼板子串口芯片丝印：如果是 CH9102 或 CP2102，Windows 需安装对应驱动；Mac 依然免驱。
macOS需要装驱动吗？
不需要 —— macOS 自带 CH340 驱动。若之前装过第三方驱动被系统拦截，到「系统设置 → 隐私与安全性」允许，或卸载后用系统自带驱动。
烧录到一半失败 / 校验错误
换一根质量好的数据线、换个 USB 口（优先直连主板，避开 Hub），关闭占用串口的程序后重试；弹窗中勾选擦除设备再烧一次。
1MB Flash 版有什么限制？
1MB 芯片放不下固件 + 文件系统，因此本固件不含文件系统分区：亮度、频谱样式、显示旋转等设置重启后不会保存（每次开机为默认值），WiFi 配网与所有显示功能不受影响。4MB Flash 的板子可用仓库里的 nodemcuv2 完整版构建。
烧录成功后设备黑屏 / 花屏 / 颜色不对
本固件适配 GC9107 128×128 屏。如果是其他屏幕（如 240×240 ST7789 的 SD2），请勿使用本页固件 —— 去原作者官网。颜色不对可在固件配置里切换旋转与背光极性。
烧完后开机要做什么？
首次开机会建热点 AI-Clock-Setup：手机连上自动弹配网页（或浏览器打开 192.168.4.1），选家里 WiFi 输密码。之后装 Windows 桥接程序（仓库 windows-app/ 自行编译，或见 GitHub Releases），同局域网自动配对。
